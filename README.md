# Gold Heist

Gold Heist is an offline GTA 6-style cover art studio for turning a small set of photographs into a bold six-panel wanted-poster composition. It runs as a plain browser app with no build step, no network requests, and no photo uploads.

Features:

- Arrange six crop-able photo panels around a large hero frame.
- Drag to pan, scroll to zoom, and reuse any loaded photo in another slot.
- Switch between four local duotone grades and write a custom cover caption.
- Export a finished cover at 1080, 2160, or 4320 pixels.

Photos remain on the device. The sample images in `app/samples/` are used for the starting layout.
